# @uzinfocom/loader

Фирменный лоадер Uzinfocom в виде атома: две дуги-электрона носятся по наклонённым
орбитам, пока идёт загрузка. Цвет по умолчанию — фирменный `#4C51C6` из логотипа.

- Без зависимостей, чистые SVG + CSS-анимация
- Веб-компонент `<uz-loader>` — работает в любом фреймворке и в обычном HTML
- React-компонент `<UzLoader />` (SSR-безопасен)
- Типы TypeScript, учитывает `prefers-reduced-motion`, доступен скринридерам (`role="status"`)

## Параметры

| Параметр   | Тип              | По умолчанию | Описание                                 |
| ---------- | ---------------- | ------------ | ---------------------------------------- |
| `size`     | number \| string | `48`         | Число = px, или любая CSS-длина (`3rem`) |
| `color`    | string           | `#4C51C6`    | Цвет линий                               |
| `duration` | number           | `0.75`       | Время одного оборота электрона, секунды  |
| `label`    | string           | `Loading`    | Текст для скринридеров                   |

## Разработка

```bash
npx serve .   # затем открыть http://localhost:3000/demo/
```
